# Sample messages

Generated by `./network/demo-iso20022.sh` from transfers that actually settled
on the live network, not from fixtures. The amounts here are the ledger's
minor units converted exactly: `5003482` paise is `50034.82`.

| File | From |
|---|---|
| `TP-HAPPY-*.pacs.008.xml` | the instruction for a transfer that settled |
| `TP-HAPPY-*.pacs.002.xml` | its completion, `ACSC` |
| `TP-ABORT-*.pacs.004.xml` | the return of a transfer that reserved value and expired |

Every personal-data field is absent because the ledger has none to put there.
See [docs/ISO20022.md](../../ISO20022.md).
